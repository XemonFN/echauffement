# ⚡ Échauffement

Petits jeux de 5 à 10 minutes pour se mettre en route avant de réviser.

- **Pays du monde** : retrouver tous les pays d'un continent (ou du monde) contre la montre. Les pays trouvés se colorent sur la carte, les oubliés s'affichent en rouge à la fin.
- **Examen civique** : QCM de l'examen pour la naturalisation (format court 20 Q / 10 min, examen blanc 40 Q / 45 min, mode « Mes erreurs »), score comparé au seuil officiel de 80 %.

Site statique (HTML/CSS/JS), aucune installation : ouvrir `index.html` ou activer GitHub Pages.

Sources : carte [world-atlas](https://github.com/topojson/world-atlas) (Natural Earth), noms de pays [world-countries](https://github.com/mledoze/countries), questions d'après la liste officielle du ministère de l'Intérieur (formation-civique.interieur.gouv.fr).
